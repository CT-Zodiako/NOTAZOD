# Student list redesign (artboard 03 "Panel lateral y mapa de calor")
Implements `design/lista-estudiantes/03-panel-mapa-calor.html` (chosen artboard; 01 and 02 are alternatives) in the real stack (React + Mantine, `app/src/App.tsx`, `app/src/App.css`, tokens in `app/src/tokens.css` / `design/system.md`).
Branch `feature/student-list-redesign`. Built and tried in NOTAZOD Test only.

## Specs
- S1: User: "damme un diseno apra donde esnta al sita de lo studintes y algo de colores tambien". The course view follows artboard 03: a left sidebar with the courses of the current semester (student count each, active course highlighted), a course header (name, group/room/split subtitle), corte tabs (Corte N · Cerrado/Abierto) and a students table. Colors come only from the design tokens and work in dark and light themes.
- S2: Heat-map grade cells. A graded cell is tinted with `--color-grade-passing` when the value is >= 3,0 and `--color-grade-failing` when < 3,0; the tint grows with the distance from 3,0 (about 10% at 3,0 up to about 55% at 0,0 or 5,0). A pending grade is violet (`--color-grade-pending`) with a striped background and reads "Pend."; an empty cell is muted "—". The "Nota del corte" cell uses `--color-grade-computedSurface` with red/green text. A legend line under the table explains the scale.
- S3: User comment on the artboard: "perdmeos funcainladiades ?". No existing functionality is lost. Every current action stays reachable: create course, delete course, sync courses, verify Campus, open Campus, upload to Campus, export/restore backup, check for updates, theme toggle, search (name, code or email), percent split editor (with the exam column name), add activity, add student, rename/delete activity from its header, open student detail from the name, edit a grade from its cell, Calificar per activity, Calificar grupo, roulette, export image, export template, close/reopen corte, grade history and undo, student groups (create, rename, delete, copy from another corte, drag/move students, students without group), and the accumulated / final grade columns.
- S4: Sidebar filters with counts: "Todos", "En riesgo" (Nota del corte < 3,0), "Con pendientes" (any pending grade in the active corte) and "Sin subir al Campus". The last one uses the result of the most recent "Verificar Campus" run in this session for the active corte; before any run it shows no count and a hint to run Verificar Campus.
- S5: A "Campus" column shows per student, for the active corte, "✓ Subida" (green), "Falta" (red) or "Distinta" (warning) from the last Verificar Campus run; "—" when there is no result for that student and corte.
- S6: A "Notas / Grupos" switch next to the corte tabs: "Notas" shows the grade table; "Grupos" shows the existing student groups UI for the active corte.
- S7: The home screen (no course selected) keeps working: course list, Crear curso, Sincronizar cursos, Verificar Campus.
- S8: Canvas comment: "tennis inches imagines para esto  el tema scuoen un switch algo asi ?". Every sidebar global action shows an outline icon (Crear curso +, Sincronizar cursos rotating arrows, Verificar Campus checkbox, Abrir Campus external arrow, Exportar copia down-to-tray, Restaurar copia up-from-tray, Buscar actualizaciones clock); the theme toggle is a switch with a sun/moon knob and the label "Tema oscuro" / "Tema claro".
- S9: Canvas comment: "que consuma menos espacio". The sidebar filters are a 2x2 grid of compact tiles: the count on top in the filter's color, a short label below ("Todos", "En riesgo", "Pendientes", "Sin subir"), the full meaning as a tooltip; the selected tile has its color border and a soft tint.
- S10: Canvas comment: "podiramo darle un color para diferencias seleccionar le color ?". Each course has a color shown as a dot before its name in the sidebar and in the course title; clicking the dot opens a palette of 6 colors (Vino, Azul acero, Dorado, Violeta, Verde, Naranja = tokens primary, grade-locked, border-focus, grade-pending, grade-passing, feedback-warning); the selected course row uses a left bar and a soft tint of its color. The choice is saved per course and survives restarts.
- S11: The course color is stored as a palette key, validated against the 6 allowed keys (anything else is rejected and leaves the stored data unchanged); existing courses without a color show the default (Vino). The schema change is additive (new nullable column) and must not alter any existing course, student or grade data.

- S12: Canvas comments: "que sol oqeu en un renglón cada curso que no ocupe tanto espacio y pon mas colores" and "mas pequenos". Each sidebar course is one 28px row (name truncated with ellipsis, full name as tooltip, student count always visible, 12px color dot). The filter tiles are single-line 26px chips ("6 En riesgo"), count in the filter color, 4px gap, still a 2x2 grid.
- S13: The course palette has 12 colors in this order: Vino, Rosa, Naranja, Dorado, Café, Oliva, Verde, Turquesa, Azul, Índigo, Violeta, Azul acero (6x2 grid). The 6 new ones are new design tokens --course-blue/teal/pink/indigo/olive/brown with light and dark values (light #2563EB #0F766E #BE185D #4338CA #4D7C0F #92400E; dark #60A5FA #2DD4BF #F472B6 #818CF8 #A3E635 #D6A26B), added to app/src/tokens.css and design/system.md. setCourseColor accepts exactly these 12 keys; anything else is still rejected without writing; the 6 existing keys keep their meaning.
- S14: Canvas comments: "quita el logo que tenemos", "suebelo mas arriba pegado al de selecciona de arriba", "pongee arriba de primero". Inside a course the sidebar shows, top to bottom: the theme switch (first, with a divider below), Cursos, Mostrar, then Campus y datos directly below the filters (not pushed to the bottom); no NOTAZOD logo/brand in the sidebar.
